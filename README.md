# gtk2aichat

Лёгкий настольный ИИ-чат на C и GTK+ 2 для старых 32-битных компьютеров.

В первой версии есть:

- OpenAI Chat Completions API и локальный Ollama;
- история обычных чатов на диске;
- временный чат, который не сохраняется;
- отдельный системный промпт для каждого чата;
- сетевой запрос в фоновом потоке, без зависания GTK;
- компактный интерфейс, рассчитанный на экран 1024×600.

## Зависимости Gentoo

Нужны `x11-libs/gtk+:2`, `net-misc/curl`, `dev-libs/json-c`, `dev-util/pkgconf` и компилятор C. Названия/доступность старого GTK2 могут отличаться в конкретном snapshot/overlay Gentoo.

```sh
make
./gtk2aichat
```

Настройки и история находятся в каталоге `~/.config/gtk2aichat/`. API-ключ записывается в `settings.conf` с правами `0600`. Для лучшей защиты ключ можно оставить пустым в настройках и запустить приложение так:

```sh
OPENAI_API_KEY='...' ./gtk2aichat
```

По умолчанию OpenAI использует `https://api.openai.com/v1/chat/completions`, модель `gpt-4o-mini`; Ollama — `http://127.0.0.1:11434/api/chat`, модель `gemma3:1b`. Эти значения можно изменить в настройках.

## Ограничения MVP

- ответы приходят целиком, без streaming;
- история хранится в одном компактном JSON-файле;
- Markdown отображается обычным текстом;
- пока нет отмены выполняющегося запроса и управления списком моделей.

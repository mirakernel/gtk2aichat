# gtk2aichat

Лёгкий настольный ИИ-чат на C и GTK+ 2 для старых 32-битных компьютеров.

В первой версии есть:

- OpenAI Chat Completions API и локальный Ollama;
- история обычных чатов на диске;
- удаление чатов с подтверждением;
- временный чат, который не сохраняется;
- отдельный системный промпт для каждого чата;
- сетевой запрос в фоновом потоке, без зависания GTK;
- потоковое отображение ответов OpenAI и Ollama;
- ввод Unicode и компактная палитра эмодзи;
- компактный интерфейс, рассчитанный на экран 1024×600.

## Зависимости Gentoo

Нужны `x11-libs/gtk+:2`, `net-misc/curl`, `dev-libs/json-c`, `dev-util/pkgconf` и компилятор C. Названия/доступность старого GTK2 могут отличаться в конкретном snapshot/overlay Gentoo.

```sh
make
./gtk2aichat
```

Настройки и история находятся в каталоге `~/.config/gtk2aichat/`. Размер окна,
положение разделителя и параметры провайдеров восстанавливаются при следующем
запуске. Чаты автоматически сохраняются после изменений и во время streaming;
файлы заменяются атомарно. API-ключ записывается в `settings.conf` с правами
`0600`. Для лучшей защиты ключ можно оставить пустым в настройках и запустить
приложение так:

```sh
OPENAI_API_KEY='...' ./gtk2aichat
```

По умолчанию OpenAI использует `https://api.openai.com/v1/chat/completions`, модель `gpt-4o-mini`; Ollama — `http://127.0.0.1:11434/api/chat`, модель `gemma3:1b`. Эти значения можно изменить в настройках.

В настройках OpenAI есть отдельное скрытое поле `OpenAI API key` и переключатель
его видимости. При запросе ключ передаётся в заголовке `Authorization: Bearer`.
Переменная окружения `OPENAI_API_KEY`, если задана, имеет приоритет над файлом.

## Ограничения MVP

- история хранится в одном компактном JSON-файле;
- Markdown отображается обычным текстом;
- пока нет отмены выполняющегося запроса и управления списком моделей.

В ленте чата диапазоны Unicode Emoji отображаются отдельным настраиваемым
шрифтом (по умолчанию `Noto Emoji`). Кнопка `😀` также вставляет часто
используемые эмодзи в поле ввода. GTK2 может показывать их монохромно.
